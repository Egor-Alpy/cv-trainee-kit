def is_color(path) -> bool:
    img = np.array(Image.open(path))
    r, g, b = img[:,:,0], img[:,:,1], img[:,:,2]
    diff = (np.mean(np.abs(r-g))
          + np.mean(np.abs(r-b))
          + np.mean(np.abs(g-b))) / 3
    return diff > 8.0

Модуль A · CLIP

Что такое CLIP и зачем он здесь

CLIP — мультимодальная модель OpenAI, обученная сопоставлять изображения с текстовыми описаниями. Позволяет получить универсальный 512-мерный вектор для любого изображения без дополнительного обучения.

  • В модуле A: вычисляем эмбеддинги только для анализа — понять как похожи изображения в пространстве признаков
  • В модуле B: те же эмбеддинги используются для кластеризации
  • В модуле C: CLIP делает zero-shot классификацию без обучения

Разбиение на K кластеров

Elbow-метод находит оптимальное K. Итеративно минимизирует сумму расстояний до центроида. Быстрый, хорошо работает когда кластеры сферические.

DBSCAN

Плотностная кластеризация

Находит кластеры произвольной формы. Шумовые точки помечает как -1. Параметр eps — радиус окрестности. Не нужно указывать K заранее.

Agglomerative

Иерархическая снизу вверх

Начинает с каждой точки как отдельного кластера, объединяет ближайшие. Ward-линкаж минимизирует дисперсию внутри кластеров.

Шаг 1 — CLIP zero-shot

Для каждого фото сравниваем со строками "a photo of barley grains on a surface", "buckwheat grains", "rice grains". Softmax → выбираем класс с наибольшей вероятностью. Без обучения.

Шаг 2 — OpenCV контуры

Отвечает на вопрос "где именно зёрна?". Бинаризация по Отсу, морфологические операции, findContours. Фильтрация по площади и aspect ratio. Результат → YOLO bbox.

Модуль C · OpenCV

Алгоритм детекции контуров

  • Grayscale + GaussianBlur(7×7) — убираем шум перед пороговой бинаризацией
  • Otsu thresholding — автоматически находит порог между тёмным фоном и светлыми зёрнами (и наоборот). Алгоритм пробует оба варианта (inv / non-inv), берёт тот что даёт больше контуров
  • MORPH_CLOSE → MORPH_OPEN — сначала закрываем разрывы внутри зерна, затем убираем мелкий шум
  • findContours(RETR_EXTERNAL) — только внешние контуры, без вложенных
  • Фильтры: площадь > 300 px², area/frame < 15%, aspect ratio 0.15–6.5
  • boundingRect → нормализованный YOLO bbox: class_id xc yc w h
def detect_seeds(img_bgr):
    gray = cv2.cvtColor(img_bgr, COLOR_BGR2GRAY)
    blur = cv2.GaussianBlur(gray, (7,7), 0)

    best_boxes = []
    for inv in [True, False]:  # оба варианта
        flag = THRESH_BINARY_INV + THRESH_OTSU \
               if inv else THRESH_BINARY + THRESH_OTSU
        _, thr = cv2.threshold(blur, 0, 255, flag)
        thr = cv2.morphologyEx(thr, MORPH_CLOSE, k, 2)
        thr = cv2.morphologyEx(thr, MORPH_OPEN,  k, 1)

        cnts, _ = cv2.findContours(thr, RETR_EXTERNAL, ...)
        boxes = [
            cv2.boundingRect(c) for c in cnts
            if MIN_AREA < cv2.contourArea(c) < MAX_AREA
        ]
        if len(boxes) > len(best_boxes):
            best_boxes = boxes
    return best_boxes
Модуль D · YOLOv8

Обучение детектора YOLOv8n

  • YOLOv8n — самая лёгкая версия YOLO: ~3.2M параметров. "You Only Look Once" — весь кадр за один проход нейросети
  • Стратифицированный сплит 80/20 — в train и val одинаковая доля каждого класса
  • 100 эпох, patience=20 — early stopping если 20 эпох без улучшения
  • mAP50 — основная метрика: mean Average Precision при IoU=0.5
  • Inference: 5-10 мс на GPU, ~300 мс на CPU
  • Confusion matrix и кривые сохраняются автоматически в output_detection/train/

Модуль D · Gradio App

Веб-приложение реального времени

  • Gradio 4+ — два режима: Camera (streaming) и Upload Photo
  • Streaming: кадры поступают каждые 0.5 с. Non-blocking lock — если модель занята, кадр просто пропускается (нет зависания)
  • Upload: blocking lock с таймаутом 15 с — ждём результат
  • RGB → BGR → RGB — Gradio даёт RGB-массив, OpenCV рисует в BGR, возвращаем RGB
  • Счётчик зёрен по классам, общий TOTAL в левом углу
  • Запуск: cd app && python app.py → localhost:7860

Архитектурные решения

Нетривиальные технические детали

Авторазметка без разметчика

Ключевой инсайт: разделить задачу на две. CLIP отвечает на вопрос "что на фото?", а OpenCV — "где конкретно?". Комбинация двух принципиально разных подходов закрывает задачу без единой ручной аннотации.

Стратификация с fallback

Если CLIP классифицировал все 200 фото в один класс, train_test_split(stratify=...) упадёт с ValueError. Обёртка в try/except с повтором без стратификации спасает весь пайплайн.

Non-blocking streaming

lock.acquire(timeout=0) для stream-колбэка вместо timeout=15. При медленном CPU новый кадр просто пропускается, очередь Gradio не переполняется, приложение не зависает.

RGB/BGR согласованность

Gradio передаёт numpy-массив в RGB. OpenCV рисует bbox в BGR-пространстве. Без явного cvtColor(RGB→BGR) перед рисованием цвета меняются местами: оранжевый barley становится синим.
