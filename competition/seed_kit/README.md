# Seed Detector — инструкция

## Что нужно сделать

**1. Подготовь фото**

Создай папку `seeds_raw/` рядом с `seed_detector.py` и положи туда все фотографии семян — примерно 200 штук, всё в одну папку без подпапок. Каждое фото — один вид семян на нём (ячмень, гречка или рис).

**2. Установи зависимости**

```bash
pip install -r requirements.txt
```

**3. Запусти обучение**

```bash
python seed_detector.py
```

Скрипт сам пройдёт все три этапа и в конце скажет метрики модели. Занимает от 20 минут до часа в зависимости от железа. Результат — файл `output_detection/best_model.pt`.

**4. Запусти приложение**

```bash
cd app
python app.py
```

Откроется браузер на `localhost:7860`.

## Как это работает — для защиты

Задача: есть 200 фотографий семян без единой разметки. Нужно обучить детектор который находит каждое зерно отдельно и считает их по классам в реальном времени.

Проблема в том, что детектор объектов (YOLO) требует размеченный датасет — для каждого фото нужно знать где именно на нём находится каждое зерно и какого оно класса. Размечать 200 фото руками — это часы работы. Поэтому разметка делается автоматически в два шага.

**Шаг 1 — классификация фото через CLIP.**
CLIP — это мультимодальная модель от OpenAI которая умеет сравнивать изображения с текстовым описанием без дополнительного обучения. Для каждой фотографии модель считает насколько изображение похоже на текст "a photo of barley grains", "a photo of buckwheat grains" и "a photo of rice grains", и выбирает наиболее подходящий класс. Так автоматически определяется что именно лежит на каждом фото.

**Шаг 2 — детекция отдельных зёрен через OpenCV.**
Классический алгоритм компьютерного зрения без нейросетей. Изображение переводится в оттенки серого, применяется пороговая бинаризация по методу Отсу (автоматически находит порог между тёмным и светлым), затем морфологические операции закрывают разрывы внутри зёрен. Алгоритм findContours находит контуры отдельных объектов, для каждого считается площадь и соотношение сторон — слишком мелкие и слишком вытянутые отбрасываются. Вокруг каждого прошедшего фильтр контура рисуется прямоугольник (bounding box) и сохраняется в формат YOLO: нормализованные координаты центра и размеры.

**Шаг 3 — обучение YOLOv8.**
Из авторазмеченных данных формируется датасет со стратифицированным сплитом 80/20 на train и val. YOLOv8n — это лёгкая версия архитектуры YOLO (You Only Look Once), детектор который обрабатывает весь кадр за один проход нейросети. Обучается 100 эпох с early stopping. На выходе — модель которая умеет одновременно находить зёрна и классифицировать их.

**Приложение** работает на Gradio. С камеры кадры поступают каждые 0.5 секунды, модель делает inference и возвращает кадр с нарисованными bbox и подписями. Параллельно обновляется счётчик по классам.

## Ключевые числа которые стоит знать

- CLIP: `openai/clip-vit-base-patch32`, zero-shot классификация без дообучения
- YOLOv8n: ~3.2M параметров, inference ~5-10ms на GPU, ~300ms на CPU
- Датасет формируется автоматически, ручная разметка не нужна
- Метрика качества: mAP50 (mean Average Precision при IoU=0.5)
