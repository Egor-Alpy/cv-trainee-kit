Напиши Gradio-приложение на Python для детекции и подсчёта семян (ячмень, гречка, рис) с двумя вкладками: реальное время с веб-камеры и загрузка фото. Стек: Gradio 4+, ultralytics YOLOv8, OpenCV, Python threading. Всё в одном файле app.py. В самом верху файла CONFIG-блок: MODEL_PATH, CLASSES, CONF_DEFAULT — это единственное место которое нужно редактировать под конкретный запуск. Ниже идут импорты, инициализация модели в try/except чтобы приложение стартовало даже без модели, глобальный threading.Lock() и переменная _last_ms для хранения времени последнего inference. Torch и CUDA проверяются один раз при старте модуля в переменную _DEVICE_STR — никогда не вызывать torch.cuda.is_available() внутри колбэков или функций рендеринга HTML, это убивает производительность в hot path. Ядро приложения — функция run_detection(img_rgb, conf, lock_timeout). Она принимает numpy-массив в RGB, порог уверенности и таймаут для захвата лока. Первым делом нормализует каналы: если изображение grayscale (2D) — делает np.stack трёх копий, если RGBA (4 канала) — берёт срез [:, :, :3]. Это критично: PNG с прозрачностью приходит как RGBA и YOLO на нём зависает без единого сообщения об ошибке. Дальше захватывает threading.Lock с переданным таймаутом — если не удалось захватить, возвращает исходный кадр и пустой Counter, не ждёт и не кидает исключений. Внутри лока вызывает model.predict(img_rgb, conf=conf, verbose=False), замеряет время через time.perf_counter(). В блоке finally всегда освобождает лок. После получения results проходит по results[0].boxes, считает Counter по именам классов, рисует bbox через cv2.rectangle с цветом из словаря COLORS_BGR, под каждый лейбл рисует залитый прямоугольник через второй cv2.rectangle с отрицательной толщиной, поверх кладёт cv2.putText белым цветом. Возвращает аннотированный numpy RGB и Counter. Таймаут лока — это архитектурное решение, а не деталь реализации. Для стримового колбэка передаётся lock_timeout=0: если модель занята предыдущим кадром, текущий просто пропускается — очередь событий не растёт, UI не зависает. Для обработчика кнопки — lock_timeout=15: пользователь нажал и ждёт результата, здесь допустимо подождать. Два отдельных wrapper-обработчика: detect_stream вызывает run_detection с lock_timeout=0, detect_upload конвертирует PIL в numpy через np.array(pil_img.convert("RGB")) и вызывает с lock_timeout=15. Конвертация через .convert("RGB") обязательна даже если кажется что изображение уже RGB — Pillow может передать в L, P, CMYK и других режимах. Сайдбар статистики реализован через функцию stats_html(counts, conf) которая возвращает HTML-строку. Никакого gr.Dataframe и gr.Markdown — только чистый HTML который Gradio рендерит через gr.HTML. Два блока: результаты и параметры. Первый блок показывает большое число семян с font-size 44px, JetBrains Mono, font-weight 500, letter-spacing -0.03em, и breakdown по каждому классу. Каждая строка breakdown — CSS grid с тремя колонками: цветная точка 9px (цвет берётся из CSS-переменной var(--classname)), блок с названием класса и процентом плюс тонкий прогресс-бар 3px высотой с CSS transition на width 0.35s, и число справа моноширинным шрифтом. Процент считается только если total больше нуля, иначе 0. Второй блок показывает время inference в мс, conf threshold и device. Время форматируется как целое число с припиской ms, если равно 0.0 — показывается em-тире. Для Gradio queue обязательно вызывать demo.queue() перед demo.launch() — без этого события блокируют друг друга на уровне сервера. Нельзя передавать в queue() параметр default_concurrency_limit=1 — это делает всё последовательным включая переключение вкладок и UI зависает пока идёт inference. Просто demo.queue() без аргументов. Стриминг с камеры реализуется через gr.Image(sources=["webcam"], type="numpy", streaming=True) как input-компонент, stream_every=0.5 — не быстрее, потому что inference на CPU занимает 300-500ms и при более частом стриме очередь растёт быстрее чем дренирует что приводит к зависанию всего приложения. concurrency_limit=1 на самом stream event — только один поток обрабатывает стрим, лишние кадры дропаются Gradio автоматически. Отдельный gr.Image(type="numpy") для вывода аннотированных кадров рядом. Вкладка загрузки: gr.Image(sources=["upload"], type="pil") — тип pil потому что Gradio возвращает PIL Image для загруженных файлов, кнопка подключена через .click(). Слайдер порога уверенности от 0.1 до 0.9 с шагом 0.05 в каждой вкладке независимо. CSS пишется как строка и передаётся в gr.Blocks(css=CSS). Дизайн-система строится на CSS custom properties: --bg #F7F5F0 тёплый офф-вайт для фона страницы, --surface #FFFFFF белый для карточек и компонентов, --ink #0A0A0A почти чёрный для основного текста, --ink2 #3A3A38 тёмно-серый для вторичного текста, --muted #8A8983 серый для меток и метаданных, --line #E6E2D8 тёплая граница, --line2 #EFEBE0 более светлая граница для разделителей внутри блоков, --accent #B4541A терракотовый для акцентного слова в заголовке, --barley #F97316 оранжевый для ячменя, --buckwheat #3B82F6 синий для гречки, --rice #22C55E зелёный для риса. Шрифты Inter и JetBrains Mono через Google Fonts @import в начале CSS-строки. Стили вкладок только через ARIA-атрибуты а не через классы вида .tab-nav button — Gradio меняет внутренние классы между версиями 4.x и 5.x, а role="tab" и aria-selected="true" стабильны по спецификации. Правило [role="tab"] задаёт прозрачный фон, убирает border кроме нижнего border-bottom 2px solid transparent, убирает border-radius и box-shadow. Правило [role="tab"][aria-selected="true"] ставит цвет var(--ink) и border-bottom-color var(--ink). Стили кнопок через button:not([role="tab"]) — это важно, иначе правила перекрывают стили вкладок. Базовый стиль: белый фон, тёмный текст, граница --line, border-radius 8px, Inter 13px font-weight 500. Для primary-кнопки отдельный класс btn-p с тёмным фоном var(--ink) и белым текстом. Не использовать variant="primary" в Gradio — это подключает внутреннюю тему которая перебивает кастомный CSS. Топбар — полностью кастомный HTML через gr.HTML. Логотип: квадрат 34x34px с border-radius 8px, чёрный фон, два абсолютно позиционированных элемента внутри — овал с цветом --barley повёрнутый на -25deg и овал с --rice повёрнутый на 20deg, имитируют зёрна. Справа pill-бейджи: зелёная точка с box-shadow если модель загружена, красная если нет. Если модель не найдена — дополнительный warn-блок с жёлтым фоном #FEF9C3 и тегом code в цвете --accent. Заголовок страницы — h2 font-size 34px font-weight 600 letter-spacing -0.025em, em-тег внутри для акцентного слова в цвете --accent без font-style italic. Каждый gr.HTML() должен содержать полностью замкнутый HTML — нельзя открыть div в одном вызове и закрыть в другом, Gradio оборачивает каждый вызов в собственный wrapper-div и закрывающий тег окажется не там где ожидается. Большие числа в сайдбаре рендерить моноширинным шрифтом JetBrains Mono потому что моноширинные цифры не прыгают по ширине при обновлении — каждая цифра занимает одинаковое место. То же касается времени inference и счётчиков по классам. Inter используется только для текстовых лейблов.
